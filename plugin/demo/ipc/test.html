JS calls registered C# object methods via CefGlue IPC channel

Method B: DotnetBridge.eval (JS → C# evaluation)

JS calls window.dotnetBridge.eval(code) → C# runs EvaluateJavaScript and returns the result.

Method C: Binary Channel (JS ↔ C#)

Binary data transfer between JS and C#. CefGlue 框架自动处理 Uint8Array ↔ byte[]（内部一层 base64）。

C# → JS: SendBinaryToJs() → window.__hostBridge._onBinaryMessage(b64)
JS → C#: window.dotnetBridge.sendBinary(Uint8Array) → BridgeBinary 事件 (byte[])
