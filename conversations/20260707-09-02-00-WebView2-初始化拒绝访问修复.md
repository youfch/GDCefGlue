# i3D 引擎开发助手

## 概述

i3D 是 Godot 引擎的一个分支，保留了 Godot 的核心架构和功能，但在类名和方法命名上有所差异。此技能帮助开发者快速进行 i3D 与 Godot 之间的类名和方法名映射转换。

## 何时使用

当用户提到以下关键词时触发此技能：
- i3D、i3D引擎、i3D开发
- i3D 与 Godot 的对比
- i3D 类名/方法名查询
- 从 Godot 迁移到 i3D
- Node 到 Item 的转换

## 核心差异规则

### 类名映射规则

**基础命名变化：**
- `Node` → `Item` （核心变化：节点统称为 Item）
- 所有继承自 Node 的类，`Node` 部分替换为 `Item`

### 方法名映射规则

**生命周期方法：**
- `_ready()` → `iStart()` （参数不变）
- `_process(delta)` → `Update()` （参数不变）
- `_physics_process(delta)` → `FixedUpdate()` （参数不变）
- `_input(event)` → `OnInput()` （参数不变）
- `_enter_tree()` → `OnEnable()` （参数不变）
- `_exit_tree()` → `OnDisable()` （参数不变）

**着色器函数：**
- `vertex()` → `vert()`
- `fragment()` → `frag()`
- `process()` → `Update()`

## 命名规律总结

| 规律 | 示例 |
|------|------|
| `Node` → `Item` | `Node3D` → `Item3D`, `XRNode3D` → `XRNode` |
| `Body` → `Bulk` | `RigidBody3D` → `RigidBulk`, `StaticBody3D` → `StaticBulk` |
| `Instance` → `Render` | `MeshInstance3D` → `MeshRender`, `ImporterMeshInstance3D` → `ImporterMeshRender` |
| `GD` → `S3` | `GD.Print()` → `S3.Print()`, `GD.Load()` → `S3.Load()` |
| 去掉下划线前缀 | `_ready()` → `iStart()`, `_process()` → `Update()` |
| 保持不变 | `GridMap`, `FogVolume`, `VoxelGI`, `ReflectionProbe` |

## 注意事项

- **参数不变**：方法名改变时，参数保持不变（如 `delta`、`event` 等）
- **继承关系**：所有 `Node` 相关的类名都改为 `Item` 相关
- **3D 后缀保留**：大部分 3D 类保留 `3D` 后缀，但基础类如 `Light3D` 变为 `Light`
- **参考 Godot 文档**：i3D 文档较少，可参考 Godot 文档理解核心概念
- **实际测试**：部分 API 可能存在行为差异，建议实际测试验证
